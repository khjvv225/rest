# BUKHARA REST - O'zbek Milliy Taomlari Restorani

![BUKHARA REST Logo](https://via.placeholder.com/200x100?text=BUKHARA+REST)

Veb-sayt va admin panel tizimi. O'zbek milliy taomlarini bron qilish, buyurtma berish va boshqarish uchun to'liq funksional platforma.

## 🌟 Xususiyatlar

### 🍽️ Asosiy Xususiyatlar
- **Menyu Ko'rish**: An'anaviy o'zbek taomlari katalogi
- **Online Bron**: Stol bron qilish tizimi
- **Foydalanuvchi Profili**: Shaxsiy profil va bron tarixi
- **Aloqa Formasi**: Mijozlar bilan aloqa

### 🛠️ Admin Panel Xususiyatlari
- **Dashboard**: Statistik ma'lumotlar paneli
- **Foydalanuvchilar Boshqaruvi**: Ro'yxatdan o'tgan foydalanuvchilar
- **Bronlar Boshqaruvi**: Barcha bronlarni ko'rish va boshqarish
- **Menyu Boshqaruvi**: Taomlarni qo'shish, tahrirlash, o'chirish
- **Sozlamalar**: Restoran ma'lumotlarini o'zgartirish

### 🔐 Xavfsizlik
- **Foydalanuvchi Autentifikatsiyasi**: Email, Google va Telefon orqali kirish
- **Admin Kirish**: Maxsus admin panel kirishi
- **Ma'lumotlarni himoyalash**: Firebase orqali xavfsiz saqlash
